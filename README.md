# CA3 LeetCode Problems — Java Solutions

Solutions are organized using the same Easy / Medium / Hard grouping as the uploaded CA3 PDF.

Each Java file contains the question number, title, LeetCode problem ID, direct problem link, and solution.

```text
CA3_LeetCode_Java_Solutions/
├── Easy/       Questions 1–9
├── Medium/     Questions 10–14
└── Hard/       Questions 15–16
```

Note: The folders preserve the difficulty grouping in your CA3 PDF, even if LeetCode's official difficulty label differs.

Submit each solution in its corresponding LeetCode editor. These are LeetCode-format classes and do not require a main() method.
